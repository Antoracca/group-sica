Couleurs officielles obligatoires : **INDIGO #0633B0 – BLANC #FFFFFF – ORANGE #F77F00** (mesurées sur les logos PNG ; l'ancien #1E2F8A / #F39200 est obsolète). Le modèle de design fourni par le client (style plateforme financière) donne la structure : canvas sombre, un accent unique, typo ferme, chiffres tabulaires, footer clair. Son jaune devient l'orange SICA, son noir devient l'indigo-nuit #060A26. Le texte sur bouton orange est l'encre #0A1033, jamais du blanc.

**Why:** le client l'a rappelé deux fois (« respecte les couleurs qu'ils ont demandées et ajuste avec le modèle pour ce qui manque », puis « j'espère que tu as respecté les couleurs ») ; le document du 17/11/2026 dit « respect obligatoire ».

**How to apply:** toute couleur passe par les tokens de `DESIGN.md`. Aucune troisième couleur de marque. Le vert et le rouge de statut ne servent qu'aux statuts. Lié à [[project-sica-refonte-v2]].
